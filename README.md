# quoridor

Play a Quoridor bot in the browser at https://evanbell.site/quoridor/. The site is static and runs entirely client-side: no server, no accounts, no analytics, no third-party requests.

Status: playable. The rules, a heuristic search (the Beginner and Normal bots) and the page are in place, with 5 x 5, 7 x 7, 9 x 9 and 11 x 11 boards. The Strong and Max bots play with a neural network and are offered only for the board sizes that have a published model (see Models and fixtures); with none published they stay off and the heuristic bots play.

## Development

Requires Node 22.12 or newer.

```
npm ci
npm run dev          # dev server at http://localhost:5173/quoridor/
npm run typecheck    # tsc, strict
npm test             # vitest
npm run build        # writes dist/
npm run verify-dist  # checks dist/ before deploy
npm run bench -- <model.onnx> [threads]   # times the network and the search in Node
```

Tests that need a model skip without one. To run them, set `QUORIDOR_TEST_MODEL_DIR` to a folder holding `model.onnx` and `golden.json` (or put them in `test-data/model/`, which git ignores). Never commit a model outside `public/models/`.

## Hosting

GitHub Pages serves `dist/`, deployed by `.github/workflows/pages.yml` on every push to `main`. Pull requests run `ci.yml`, which runs the same checks without deploying.

Pages cannot set response headers, so `coi-serviceworker.js` adds the COOP and COEP headers that `SharedArrayBuffer` (multithreaded WebAssembly) needs. On the first visit it registers and reloads the page once. When the page is not cross-origin isolated, inference falls back to one thread.

## Models and fixtures

Models (`public/models/<id>/`) and test fixtures (`fixtures/`) are generated by tooling in a separate private repository and arrive as reviewed pull requests. They are never edited by hand.

## Contributing

- TypeScript in strict mode, built with Vite, tested with Vitest. No UI framework.
- Dependencies are pinned to exact versions and `package-lock.json` is committed. Keep them minimal.
- `fixtures/**` and `public/models/**` are generated by tooling in a separate private repository. Never edit them by hand; a wrong fixture is fixed at its source.
- `public/coi-serviceworker.js` is vendored unmodified. Configure it in `public/coi-config.js`.
- The site is served under `/quoridor/` (`base` in `vite.config.ts`). No cross-origin subresources, third-party requests or analytics.
- Never commit local paths, user or host names, or secrets.
- Commit with the GitHub noreply address, and no `Co-Authored-By` trailer.
- Keep pull requests small and single-concern. State what changed and why, what to look at (ranked by risk) and how it was verified. Claim correctness only with tests and speed only with measurements.
- Before a PR run `npm run typecheck`, `npm test`, `npm run build` and `npm run verify-dist`.
